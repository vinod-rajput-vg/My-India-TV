FAQ

Everything you need to know.

Clear answers before you install or explore the project.

Is this a built-in video player?

No. The Android app launches compatible installed players through Android's ACTION_VIEW intent.

Is the APK a public release?

Not yet. The current project has a successful GitHub Actions debug build, but no published GitHub Release asset. The site links to the build workflow instead of inventing a direct APK URL.

Are all channel streams guaranteed to work?

No. Availability depends on the configured stream URLs, network conditions, third-party sources and installed playback support.

Where is the source code?

The complete Android project, channel data, artwork and build workflow are available in the GitHub repository.
